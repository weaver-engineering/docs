## Documentation Standards
All Weaver Engineering projects should include a `README.md` file with and brief overview of the project
in their docs repo.

The `REEADME.md` should include a link to an `about-{project-slug}.md` which should include *front-matter*
about the project. For example the issue management provider for the project, so that agents and tools
have a quick reference for details about a project.
